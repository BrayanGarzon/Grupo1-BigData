# Parcial Big Data — Auditoría de un sistema de ventas

Una empresa recibió un sistema en Python para analizar sus ventas, pero el
programa presenta problemas que hacen que sus resultados no sean confiables.

Su trabajo es **analizar el código existente, identificar los problemas,
corregirlos y completar una funcionalidad solicitada por la empresa**.

### Puede consultar
- Apuntes.
- Talleres.
- Código realizado en clase.
- Documentación de Pandas.

### Objetivos

El programa debe permitir:

1. Cargar `datos/ventas.csv`.
2. Limpiar y preparar los datos necesarios para el análisis.
3. Crear `total_venta` como `precio × cantidad`.
4. Encontrar el producto con mayor valor total vendido.
5. Encontrar la ciudad con mayor valor total vendido.
6. Calcular el valor total de todas las ventas.
7. Agregar un resumen del valor vendido por categoría.

### Condiciones

- No modificar `ventas.csv`.
- No escribir los resultados manualmente.
- Puede modificar el código existente.
- El programa debe ejecutarse sin errores.
- No se indica qué función de Pandas debe utilizar.

### Entrega

Entregar el proyecto corregido y funcionando.

El informe final debe ser claro y mostrar los resultados obtenidos.

> Una línea puede ejecutarse sin producir errores y aun así estar haciendo
> algo incorrecto. Compruebe que los resultados tengan sentido.
